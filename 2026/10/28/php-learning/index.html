发表于 2026-10-28 分类于 web安全学习

本文记录 PHP 基础语法、弱类型比较、超全局变量与常见函数，并通过类、对象、构造方法和继承入门面向对象。

学习地址

基础语法

PHP 脚本在服务器上执行，然后将纯 HTML 结果发送回浏览器

PHP代码的基本格式

PHP变量

  • 变量以 $ 符号开始，后面跟着变量的名称

  • 变量名必须以字母或者下划线字符开始

  • 变量名只能包含字母、数字以及下划线（A-z、0-9 和 _ ）

  • 变量名不能包含空格

  • 变量名是区分大小写的（$y 和 $Y 是两个不同的变量）

    这些和其他语言的差别不大

PHP 是一门弱类型语言

这是什么意思那，就是不必向 PHP 声明该变量的数据类型，和C语言对比，比如c语言定义一个整型变量需要int a; 但是在PHP中就不需要，PHP 会根据变量的值，自动把变量转换为正确的数据类型。

PHP数据类型和比较

  • String（字符串）

  • Integer（整型）

  • Float（浮点型）

  • Boolean（布尔型）

  • Array（数组）

  • Object（对象）

  • NULL（空值）

  • Resource（资源类型）

    数组这里array() 和其他语言不太一样，重点学习一下

超级全局变量

PHP中预定义了几个超级全局变量（superglobals） ，这意味着它们在一个脚本的全部作用域中都可用。 你不需要特别说明，就可以在函数及类中使用。

PHP 超级全局变量列表:

  • $GLOBALS

  • $_SERVER

  • $_REQUEST

  • $_POST

  • $_GET

  • $_FILES

  • $_ENV

  • $_COOKIE

  • $_SESSION

    也就是在这些输入点，可能会导致很多的漏洞点，这里借用一下学长总结的表格

    变量 用途 渗透关注点
    $_GET URL 参数 最常见注入入口
    $_POST POST Body 表单注入入口
    $_REQUEST GET+POST+Cookie 参数来源混乱，易绕过
    $_COOKIE Cookie 认证伪造、反序列化
    $_SESSION 会话 会话固定、会话劫持
    $_SERVER 服务器信息 信息泄露、HTTP_* 头伪造
    $_FILES 上传文件 文件上传漏洞
    $GLOBALS 全局变量 变量覆盖

这里先把extract()学习一下

extract($_GET)作用是 将GET请求的参数直接解析为变量并覆盖原有变量；

正常代码无法直接控制 $secret，但是 extract() 会自动创建/覆盖任意变量。
也就是说：我们在URL传什么参数，服务器就会生成什么变量。

这里extract接收GET的参数，由于这个函数可以直接覆盖GET到的参数，所以就直接可以在url中加上?secret=admin可以直接覆盖掉原本的参数，直接就可以输出flag

面向对象

可以把它们串成一条线来理解：类定义对象有哪些数据和行为；序列化保存对象的数据；反序列化恢复对象。如果恢复的数据由外部控制，而对象又会自动执行某些操作，就可能产生漏洞。

class car 定义一个类car，也就相当于car的设计图

public $color 在类中声明一个名为 color 的公开属性，用于保存每个对象的颜色,也就相当于规定了在Car中都需要有color（颜色）这个属性，意思就是汽车的设计图中得设计一下颜色
