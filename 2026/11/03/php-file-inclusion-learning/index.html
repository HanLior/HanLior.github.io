漏洞函数

函数名 功能说明
include() 找不到文件时仅抛出警告，脚本继续执行
include_once() 与include()功能一致，但避免重复包含（同一文件仅加载一次）
require() 找不到文件时抛出致命错误，脚本直接停止执行
require_once() 与require()功能一致，且避免重复包含

PHPinclude-labs

文件包含漏洞的核心是：程序本来只想加载指定文件，却让用户输入影响了加载哪个文件，而且没有严格限制范围。 攻击者因此可能让程序读取敏感文件，或将不可信文件当作代码执行。

level6

php://伪协议

包装器 主要功能 常见用法 关键说明
php://input 读取 HTTP 请求体的原始内容 file_get_contents('php://input') 只读；常用于读取 POST 原始数据
php://filter 对其他流进行读取或写入过滤 php://filter/read=convert.base64-encode/resource=flag.php 常用于编码、解码、大小写转换和源码读取
php://memory 创建只存在于内存中的临时流 fopen('php://memory', 'r+') 可读写；每次打开通常是独立流
php://temp 创建临时流，超过限制后可写入临时文件 fopen('php://temp', 'r+') 默认超过一定大小后使用临时文件
php://output 直接写入 PHP 的输出缓冲 fwrite(fopen('php://output','w'), 'Hi') 只写；效果类似输出内容
php://stdin 读取命令行标准输入 fgets(STDIN) 主要用于 CLI 命令行程序
php://stdout 写入命令行标准输出 fwrite(STDOUT, 'Hi') 主要用于 CLI
php://stderr 写入命令行错误输出 fwrite(STDERR, 'Error') 主要用于 CLI 报错或调试
php://fd/N 访问指定的文件描述符 fopen('php://fd/3', 'r') N 是操作系统文件描述符编号

Level18

require/include_once 缺陷

第一次已经包含,直接再次包含 flag.php 会被跳过。利用 /proc/self/root 的多级符号链接，让 PHP 判重时看到“不同路径”，但实际仍指向同一个文件。重复约 25次是因为每个 /proc/self/root 涉及多级符号链接，超过 PHP 的路径解析限制后，判重哈希中的路径与第一次包含的路径不同
